## Contracts

### Delta schema (already in `pymolt/delta/models.py`, additive)
- `DeltaReport.subject`: `"dependency"` or `"python"`.
- `DeltaReport.sides`: `{"old": "probe:<…>" | "knowledge:<file>@<date>", "new": …}`.
- `DeltaReport.import_errors[]`: `{module, side, error, origin, cause}`.
- `DeltaFact.basis`: `{"old": "probe" | "knowledge" | "import-statement", "new": …}`.
- `DeltaFact.removed_in`, `deprecated_in`, `warns_since` and `origin` (`stdlib` | `site-packages:<dist>`).
- Unset additions are left out of dumps, so dependency reports dump exactly as before.

### Runner (1a-1 owns; others import)
`pymolt/adapters/python_runner.py`:
```python
class Mount(BaseModel): source: str; destination: str          # host abs path ↔ container path
class RunnerSpec(BaseModel):
    kind: Literal["container"] = "container"
    name: str; container_id: str; image: str | None = None
    platform: str | None = None; emulated: bool = False        # image platform ≠ host arch
    workdir: str | None = None; mounts: list[Mount] = []
    executable: str = "python"                                 # inside the container
def inspect_container(name_or_id: str) -> RunnerSpec | None     # docker inspect adapter
def to_host(spec: RunnerSpec, path: str) -> str | None          # /work/x -> <host>/x via mounts
def to_container(spec: RunnerSpec, path: str) -> str | None
def runner_available(spec: RunnerSpec) -> tuple[bool, str | None]   # (running?, why not)
def run_in(spec: RunnerSpec | None, argv: list[str], *, stdin: str | None, cwd: str | None,
           timeout: float) -> subprocess.CompletedProcess   # None = local
```
- **Where it's stored:**
  - `EnvConfig.runner: RunnerSpec | None`, set by `setup --container`;
  - `ContractSlot.runner: RunnerSpec | None`, set by a capture that ran in a container;
  - `Interpreter.runner: RunnerSpec | None`, with `executable` meaning the path inside the runner.
- **`engine.run_probe(executable, root, request, *, runner=None, …)`:** a keyword addition; the local behaviour is unchanged. Under `runner` it uses `docker exec -i [-w <container path of root>] <name> <exe> -B -c <probe>`, with the request on stdin, and copies nothing in. Timeouts are ×4 when `emulated`. The cache key includes `container_id` and the image, and the stamps are read inside the runner.
- **Probe results gain `import_errors`:** a module that raises on import is recorded there, never as a missing name.

### Stdlib data (1b-1 owns; others import)
`pymolt/core/stdlib.py`:
```python
def is_stdlib(top: str) -> bool                                  # union over 2.7 and 3.0–3.14
def module_lifetime(module: str) -> tuple[str, str | None] | None # ("3.0", "3.11") for imp
def name_lifetime(dotted: str) -> tuple[str, str | None] | None   # ("3.0", "3.9") for collections.Iterable
def present_in(dotted: str, version: str) -> bool | None          # from data; None = unknown
def changes_for(dotted: str) -> list[StdlibChange]                # curated entries (symbol or module prefix)
def data_stamp() -> str                                           # "knowledge:stdlib_lifetimes@<date>"
@dataclass(frozen=True) class StdlibChange: id; symbols; kind; deprecated_in; warns_since;
    removed_in; successor; same_object; successor_since; fix; hint; shimmed_by; source
```
- **Files:** `pymolt/knowledge/stdlib_lifetimes.json` (generated by `bench/stdlib_sweep/`; never hand-edited) and `pymolt/knowledge/stdlib_changes.json` (curated, about 50 entries).
- A small seed version of both lands **first**, so 1b-2/1b-3 can test against it. The full sweep replaces the generated file later.

### Stdlib sites (1b-2 owns; 1b-3 imports)
`ContactMap.stdlib_sites: list[StdlibSite]`, where:
```python
class StdlibSite(BaseModel):
    spelling: str          # resolved through the file's imports: "collections.Iterable", "imp.reload", "imp"
    module: str            # stdlib top-level: "collections"
    file: str; line: int   # project-relative
    kind: Literal["import", "from", "attr", "call", "class-base"]
    reached_at: Literal["import", "call"]
    guard: dict | None     # {"kind": "fallback" | "guarded-fallback" | "broad" | "version", "detail": str}
```
- `Contact` gains `line`.
- There is a per-file cache at `.pymolt/cache/contacts/<sha256>.json`, keyed by content and contact-map version.

### Python delta and risks (1b-3 owns)
- **Data model:** `pymolt/pyversion/facts.py::python_delta(...) -> DeltaReport(subject="python")`.
  - Target side: the target interpreter, through `run_probe` with `{"paths": spellings, "roots": stdlib tops}`.
  - Base side: from data in this wave (`quality: "partial"`). With a runner it is probed after integration.
- **Compile check:** `pyversion/compile_check.py`.
- **Prediction:** `verify/predict.py::predict_python_risks`, with the design's python tier table and its D12 rule.
- **Plan:** `MigrationPlan.python` and `compile_findings`. Python risks are predicted without a baseline.
